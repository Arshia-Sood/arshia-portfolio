# Arshia Sood — Portfolio Website

A responsive, dark-themed portfolio built with plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Files
- `index.html` — page content and metadata
- `styles.css` — responsive layout and visual styling
- `script.js` — mobile navigation and dynamic copyright year

## Before publishing (important)
Open `index.html` and replace these placeholders with your real details:
1. `YOUR_EMAIL_HERE` — your email address (used in the email button).
2. `YOUR_LINKEDIN_URL_HERE` — your LinkedIn profile URL.
3. `YOUR_RESUME_FILE_HERE` — the URL to your resume PDF after you add it to the site.
4. Check all project details and links. The current GitHub profile link is `https://github.com/Arshia-Sood`; the TrustLens repository and TravelMate demo are linked based on the details available.

You can add your resume PDF to this folder (for example, `resume.pdf`) and change `YOUR_RESUME_FILE_HERE` to `resume.pdf`.

## Preview locally
- Extract the ZIP.
- Open `index.html` in your browser.
- For a better local development workflow, open the folder in VS Code and use the Live Server extension.

## Deploy free with GitHub Pages
1. Create a new public repository on GitHub, for example `arshia-portfolio`.
2. Upload the contents of this folder (not the ZIP itself) to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The URL will look like `https://YOUR_GITHUB_USERNAME.github.io/arshia-portfolio/`.

## Deploy with Netlify
1. Open Netlify and sign in.
2. Choose **Add new site → Deploy manually**.
3. Drag the extracted folder into the deploy area, or connect the GitHub repository.
4. Netlify will provide a public URL.

## Content notes
The portfolio intentionally avoids claims about unverified metrics or production scale. Before sending the link to recruiters, verify your grades, project features, achievement names, and all links. Add your actual contact information and resume link first.
